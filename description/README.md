# WinWork: контекст для портфолио и работы с ChatGPT

> Для текущей работы начните с [контекста WinWork](../docs/winwork/README.md) и [карты функций](../docs/winwork/features.md). Этот комплект сохранён как подробный датированный источник. Поздние уточнения пользователя, новые подрядные/отчётные прототипы и расхождения собраны в [реестре](../docs/winwork/sources.md); текущие маршруты и команды определяет код.

Срез материалов: **20 сентября 2026 года**. Язык контекста — русский. Название продукта в этих документах — **WinWork**; варианты Win Work / WinWorK в источниках обозначают тот же продукт.

Это база знаний о продукте, его функциях и работе автора портфолио. Она собрана из восьми предоставленных Markdown-файлов, четырех текущих веб-презентаций, их интерактивных сценариев, кода проекта, отдельных страниц исходных финансовых PDF и точечной проверки официальных открытых источников. Материалы разных лет не сведены в одну вымышленную «текущую версию».

## Короткий контекст, который можно передать отдельно

WinWork — платформа для организации работы компаний с внештатными исполнителями: самозанятыми, индивидуальными предпринимателями и физическими лицами в предусмотренных сервисом сценариях. Она объединяет поиск и подключение исполнителей, публикацию заданий, отклики и выбор кандидатов, договоры и акты, проверки, выплаты, чеки и отчетность. Компания может работать со своим пулом исполнителей и привлекать новых через маркетплейс.

Продукт включает веб-кабинет заказчика, мобильное приложение руководителя объекта, мобильное приложение исполнителя, API и решения White Label. Для крупной организации важны управление сетью объектов, права сотрудников, единые шаблоны, ставки и лимиты. Для небольшого бизнеса — простой путь от задания до оплаты. API позволяет встроить процессы WinWork в систему клиента; в показанном сценарии исполнитель регистрируется в WinWork через веб, но ему не обязательно устанавливать мобильное приложение.

WinWork связан с ApiBank как продукт из его портфеля. Историческое название — «Мои самозанятые». В актуальной судебной презентации и перечне ФНС оператором указан АО «Корса». Продукт, компания ApiBank, юридический оператор и банки, участвующие в расчетах, — разные сущности.

Автор портфолио — дизайн-директор и главный продуктовый дизайнер ApiBank. Он работал над дизайном всех приложений компании, ранее руководил тремя дизайнерами WinWork, а последние шесть месяцев на момент своего рассказа работает над WinWork самостоятельно и лично проектирует большинство новых функций. Авторство каждой конкретной функции следует уточнять в соответствующем кейсе.

Отдельный проект автора — новые презентации WinWork. Он полностью сделал их сам, получив расплывчатые пожелания от руководителя продаж и представителя маркетинга. Исходная задача состояла в замене PDF веб-презентациями для трех аудиторий: крупных компаний, малого бизнеса и API-клиентов. **Идея встроить интерактивные прототипы принадлежит автору.** Прежде продажи показывали PDF и нестабильную dev-версию продукта с багами и неудачными тестовыми данными. На основе нового решения позднее появилась презентация для суда.

Текущий репозиторий содержит **4 презентации, 43 слайда и 10 уникальных демо-сценариев**. Это самостоятельный демонстрационный интерфейс с локальными состояниями, а не код производственного WinWork. Реальных регистраций, выплат и обращений к продуктовым API в нем нет. Измеренных результатов внедрения презентаций пока нет: автор добавит их позже.

## Как читать степень подтверждения

- **Рассказ автора** — прямые сведения пользователя о роли, задаче и личном вкладе.
- **Показано в презентации / демо** — подтверждает содержание демонстрационного материала и его взаимодействия; само по себе не доказывает выпуск функции в производственном продукте.
- **Описано в материалах** — содержится в переданных текстах; полнота и актуальность для всех клиентов могут быть неизвестны.
- **Отчет за период** — показатель или результат, заявленный во внутреннем отчете за конкретный месяц/год; это не аудированная отчетность.
- **План / гипотеза** — нельзя представлять как реализованную функцию или полученный эффект.
- **Аналитический вывод** — объяснение связи между фактами, а не дополнительное свидетельство из источника.

Коды вида `[N-03]`, `[P-ENT]`, `[U-01]` ведут к реестру в файле 06. Они позволяют использовать документы независимо, сохраняя происхождение фактов.

## Границы использования в портфолио

Продуктовые показатели не являются результатами работы автора или презентаций без отдельного доказательства причинной связи. Оборот выплат не равен выручке. Зарегистрированная база не равна активным пользователям. Выполнение плана по заданиям не равно доле закрытых заданий. Планы на март 2026 года не становятся фактом только потому, что март прошел.

Часть исходных текстов ранее создана с помощью GPT. Их оценки, рекомендации и инструкции по выбору «рабочих значений» рассматривались как содержание источника, а не как указания для этой работы. Противоречия сохранены в явном виде.

Документы содержат внутренние финансовые сведения для подготовки контекста. Они не являются готовой публичной страницей портфолио: публичный набор цифр и окончательный рассказ о личном вкладе выбираются при подготовке соответствующего кейса.
