# Презентация WinWork для суда — материалы для печати

Подготовлено 30 сентября 2026 года из актуальной локальной Court-сборки.

**64 PNG, каждый 1920 × 1080:** все шесть слайдов суда и все страницы шести flow, открывающихся на этих слайдах. Включены формы до и после заполнения, меню, вкладки, отзывы трёх исполнителей, результат выбора и подтверждение оплаты. Длинные страницы представлены кадрами «Верх» и «Низ» с перекрытием.

Печатайте по первым трём цифрам имени: **001 → 064**. Порядок соответствует показу: слайд, связанные с ним flow, следующий слайд. Две цифры после общего номера обозначают шаг внутри flow; последующие цифры — часть длинной страницы.

Синие рамки выделяют кнопки действий для перехода дальше или просмотра дополнительных страниц. Текстовые поля, дата, время, СМС-код и поля выбора не имеют синих обводок. На финальных экранах и экране загрузки рамок нет. На нижней части длинной страницы целевая кнопка иногда остаётся на предыдущем кадре.

Для печати скрыты кнопки управления презентацией, сброса и закрытия flow; внешний фон flow сделан белым. Мобильная поверхность показана целиком в 430 × 979. На странице личных данных панель действий размещена под формой, чтобы адрес не перекрывался; рамки вкладок показаны без обрезания. Эти изменения применены только в браузере при съёмке. Код и поведение презентации не изменялись.

Для печати изображения целиком выберите альбомную ориентацию, одно изображение на страницу и вписывание в область печати без обрезания. CSV «Порядок печати.csv» содержит тот же список для проверки комплекта.
