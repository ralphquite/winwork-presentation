# Презентация WinWork для суда

Court — отдельный материал для последовательного объяснения того, как заказчики и исполнители пользуются WinWork. Он возник на основе sales-презентаций, чтобы показывать подготовленные сценарии без зависимости от dev-стенда. Это описание назначения демонстрации, не фактов конкретного дела или результата рассмотрения. Происхождение — [контекст проекта](project-context.md) и [источники](winwork/sources.md).

## Что показываем

| Сцена      | Содержание                             | Демонстрация                                     |
| ---------- | -------------------------------------- | ------------------------------------------------ |
| `court-01` | Сервис поиска подработки; перечень ФНС | Внешняя пользовательская ссылка                  |
| `court-02` | Доступ заказчика                       | Регистрация юридического лица и создание задания |
| `court-03` | Доступ исполнителя                     | Регистрация и путь отклика                       |
| `court-04` | Выбор кандидатов                       | Отклики, сведения, принятие/отказ                |
| `court-05` | Подтверждение оплаты и объяснение НПД  | Локальный сценарий оплаты выполненного задания   |
| `court-06` | Статистика утверждённого слайда        | Экспорт Pencil                                   |

Порядок и привязки определяет [court.ts](../src/presentation/config/court.ts). Первые пять слайдов собраны кодом в `public/court-slides/`, шестой экспортирован из Pencil. Регистрация, подпись и платёж не вызывают реальные сервисы. Числа и юридические формулировки — содержание утверждённого материала; перед содержательным обновлением их проверяют отдельно, а не объявляют актуальными из-за наличия в HTML.

## Как открыть

- Web: публичный `/court` использует отдельный bundle. Защищённые sales-assets не становятся публичными вместе с ним.
- Offline: `pnpm build:court:offline` → `dist/offline/Открыть презентацию WinWork.html`. Открывать в Google Chrome; сервер и сеть для показа не нужны.
- Печать: [вариант с логотипами](<../For Printing/with_logos/README.md>) и [вариант без логотипов](<../For Printing/without_logos/README.md>). Это сохранённые наборы кадров со своей датой и порядком печати, не автоматически обновляемая сборка.

В offline-файле постоянно видны предыдущий слайд, следующий и возврат к началу. История хранится в hash. Клик мимо действия внутри демо временно выделяет нужный элемент обводкой; на фоне слайда и в шторке выбора исполнителей подсказок нет. Ссылка на перечень ФНС обращается к сети только по действию зрителя.

## Где менять и как проверять

Входы: `src/court/main.tsx` и `src/court/offline-main.tsx`; сборка: `vite.court.config.ts`, `vite.court-offline.config.ts`, `scripts/package-offline-court.mjs`. Сценарии переиспользуются из `src/presentation/flows/`; отдельного движка Court нет.

Начать с `public-court-presentation` в [context-index.json](agents/context-index.json). Для изменений кода выполнить `pnpm check` и Court-матрицу из [AGENTS.md](../AGENTS.md): шесть сцен и пути демо, история, сброс, клавиатура, фокус, встроенные изображения, отсутствие runtime HTTP-запросов в Chrome через `file://` без сети. Печатные кадры сравнивать с обновлённой версией отдельно.
