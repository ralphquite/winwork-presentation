Лимиты для каждого объекта

При создании объекта выберите доступные виды деятельности и задайте лимиты для каждого из них.

Руководитель работает в пределах бюджета объекта

Он может создавать задания по выбранным видам деятельности в пределах остатка лимита.

Это правило действует и для заданий через подрядчика.
